# JAVA服务端开发

Java工程师/专家 - 营销中台/导购活动/百亿补贴（基础电商）

岗位职责

1.参与营销平台内招选搭投、优惠系统、百亿补贴等核心流程的设计和开发工作，独立负责业务模块的需求对接和技术改造。

2.参与重点项目及技术方案设计，协调和对接各方技术资源完成方案落地，并撰写高质量的开发文档。

3.参与业务平台的系统重构与架构升级。

任职要求

1. 1年以上的互联网行业工程研发经验。

2.JAVA基础扎实，熟悉业界流行的开源框架和组件并有一定的理解深度。

3.熟悉分布式系统的设计思路，对微服务常用框架有使用经验。

4.熟悉MySQL、Redis、ElasticSearch等主流存储引擎的原理，具备相关的性能调优能力。

5.责任心强，思路清晰，技术视野开阔，对业界新技术敏感，喜欢钻研，具有良好的学习能力并注重团队合作。

6.参与过大规模业务系统开发，有高并发系统调优经验的优先。
